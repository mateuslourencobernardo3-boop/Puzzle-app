# Título: Política de Privacidade - Quebra-Cabeça Desafio

Este aplicativo ("Quebra-Cabeça Desafio") é oferecido como um aplicativo gratuito com suporte de anúncios. Este serviço é fornecido sem custos e destina-se ao uso no estado em que se encontra.

Esta página é usada para informar os visitantes sobre nossas políticas com a coleta, uso e divulgação de Informações Pessoais se alguém decidir usar nosso Serviço.

Coleta e Uso de Informações: Para uma melhor experiência, ao usar nosso Serviço, podemos exigir que você nos forneça certas informações de identificação pessoal. As informações solicitadas serão retidas por nós e usadas conforme descrito nesta política de privacidade. O aplicativo usa serviços de terceiros que podem coletar informações usadas para identificá-lo, com destaque para o Google AdMob (para veiculação de anúncios personalizados ou não personalizados).*

Cookies: Cookies são arquivos com uma pequena quantidade de dados que são comumente usados como identificadores exclusivos anônimos. Este Serviço não usa esses "cookies" explicitamente. No entanto, o aplicativo pode usar código de terceiros e bibliotecas que usam "cookies" para coletar informações e melhorar seus serviços.*

Segurança: Valorizamos sua confiança em nos fornecer suas informações pessoais, por isso estamos nos esforçando para usar meios comercialmente aceitáveis de protegê-las. Mas lembre-se de que nenhum método de transmissão pela internet ou método de armazenamento eletrônico é 100% seguro e confiável.*

Alterações a Esta Política de Privacidade: Podemos atualizar nossa Política de Privacidade periodicamente. Assim, é recomendável que você revise esta página periodicamente para quaisquer alterações.*

Se você tiver alguma dúvida ou sugestão sobre nossa Política de Privacidade, não hesite em entrar em contato conosco.
